라벨 검토

AI가 제안한 수치 라벨과 신뢰도 0.9 미만 라벨을 사람이 확인합니다. 승인한 수치는 측정값 표로 올라갑니다.

사전 라벨을 거절할 때 같은 앞뒤 낱말의 같은 표기를 다음부터 라벨하지 않습니다. 작업대의 ‘배운 것’에서 끌 수 있고, 되돌리기(U)를 하면 배운 것도 꺼집니다.

API 키 관리

자료 수집 출처와 클라우드 크롤러·파서가 쓰는 키를 발급받아 여기에 저장합니다. 저장하면 앱을 다시 켜지 않아도 바로 쓰입니다.

키는 어디에 저장되나 — 이 PC의 Windows 자격 증명 관리자(지금 로그인한 Windows 계정으로 암호화)에만 둡니다. 설정 파일·DB·로그·내보내기에는 쓰지 않고, 화면에도 끝 4자리만 보입니다.

무엇이 밖으로 나가나 — 각 키는 그 키를 발급한 서비스로만 갑니다(검색·호출할 때 함께). 같은 이름의 환경 변수가 있으면 그 값이 먼저 쓰입니다.

설정 값(비밀 아님) — 환경 변수로만 바꿉니다

도움말과 단축키

어디서나

Ctrl+K · /머리줄 검색칸으로?이 도움말Esc대화상자·메뉴 닫기

입력칸에 글을 쓰는 동안에는 /·?와 아래 단축키가 동작하지 않습니다.

(?) 도움말 단추

메뉴 이름·화면 제목·카드 제목 옆의 (?)를 누르거나(또는 초점을 두고 Enter) 마우스를 잠시 올리면, 그 기능이 무엇을 하는지·언제 쓰는지·어떻게 쓰는지·PC 밖으로 무엇이 나가는지와 안내서 장 번호가 나옵니다. Esc나 바깥을 누르면 닫힙니다. 머리줄의 도움말 표시로 모두 숨기거나 다시 보일 수 있습니다.
