## 계약과 다른 점·글쓴이가 알아야 할 것

- **경로 가림**: 화면에 나오는 데이터 폴더 경로를 찍기 전에 화면에서 `C:\ByOrbit-RD`로 바꿨습니다(s01·s24의 받은편지함 경로, s07의 데이터 폴더·MCP 설정 경로). s07의 Claude Code 경로는 `claude.CMD`로만, s19의 kordoc 위치는 `C:\04_byorbit-agent`로 보입니다. 실제 사용자 이름이 들어간 경로는 어느 그림에도 없습니다.
- **AI 라벨 결과는 대역으로 만든 것**: 유료 AI 호출을 하지 않으려고, 미리 정한 라벨을 저장하는 로컬 대역 엔진으로 앱의 라벨 실행(run)을 돌렸습니다. 그래서 s01의 AI 라벨 카드, s03의 검토 대기 라벨, s20·s21의 'AI' 라벨은 실제 Claude가 만든 것이 아닙니다(화면 모양과 흐름은 실제와 같음). 승인 2개·거절 1개는 앱 API로 했습니다.
- **s24 첫 화면**: 같은 데모 폴더에서 '기본 프로젝트'로 바꿔 빈 자료함을 찍었습니다. 위쪽 '라벨 검토' 탭 옆에 대기 수 배지 **6**이 보입니다. 정말 처음 설치한 상태라면 이 배지가 없습니다.
- **s06 AI에 묻기**: 질문 칸에 앱 안내 문구와 같은 예시 질문만 넣었고 '묻기'는 누르지 않았습니다. 답변 칸은 없습니다.
- **s08 수집 검색**: Europe PMC는 처음 검색에서 시간 초과, Semantic Scholar는 '혼잡해 잠시 막힘'(키 없는 공용 한도) 오류가 났습니다. 저장 검색 실행에서는 Europe PMC가 정상으로 10건을 받았습니다. 수집함 카드는 출처별로 하나씩 보이도록 4개만 남겼습니다(실제 목록은 44건).
- **s10 공정 흐름**: 흐름 카드가 가로로 길어 7번째 단계(포장·저장)는 화면 오른쪽 밖에 있습니다(앱에서는 가로 스크롤). 모델 근거 배지는 '문헌 3/3·실측 2·설비 사양 4·가정 18·내 입력 7'입니다.
- **s11 실험 데이터**: 표가 창 폭을 넘어 칸 너비를 화면에서 줄여서 찍었습니다(값은 그대로). '저장 기간' 칸은 숨김 처리된 열이라 보이지 않습니다.
- **s12 결과·보정**: 길이를 줄이려고 '런 × 단계', '민감도', '다음 실험 제안' 카드와 보정 카드의 점별 세부 표를 숨겼습니다. 보정은 미리보기만 했고 '적용'은 하지 않았습니다.
- **s14 분석 결과**: 그림 1과 보조 그림·방법 문장은 숨겼습니다(그림 1은 s25로 따로). 예시 데이터는 2종(구연산·염산), 분석 n = 53입니다.
- **s17 예측 근거**: '근거 보기'의 파라미터 7개 중 2개(얼음 증기압 식·선반 열전달계수)만 남기고 나머지는 숨겼습니다. 예측 화면의 기본 방식은 동결건조입니다.
- **s19 파싱**: pdfplumber를 한 번 실행해 나란히 비교를 채웠고 '이 결과로 다시 청킹'은 누르지 않았습니다. '결과' 표 카드는 숨겼습니다.
- **s20 청크 / 되돌리기**: 계약에 있던 '청크 한 번 고치고 되돌리기'는 하지 않았습니다. 화면은 기본 상태(짧음 표시 2개)입니다.
- **s21 수동 라벨**: 팝업을 띄운 상태로 찍은 뒤 저장했습니다. 그래서 보고서의 "100 μm"이 사람 라벨로 측정값 표에 올라갔고, 이것이 s22의 '라벨 사례 1개'입니다. s22의 규칙(쪽 번호 잡음 줄, 모든 PDF)·동의어("사과 착즙 부산물")·부정 사례(보고서의 "사과박" 거절)는 데모용으로 작업대 API를 불러 만들었습니다.
- **s23**: 실제 설치를 다시 하지 않고, install.ps1이 찍는 문구와 `app.cli init`의 실제 JSON 출력을 터미널 모양 HTML로 그렸습니다(`src/s23-install.html`). Python·Claude Code 버전 줄은 이 PC 값입니다.
- **크기**: 화면 캡처는 계약의 '폭 최대 2400 px'에 맞춰 줄였습니다. 인포그래픽은 2배율 그대로라 3200 px입니다.
- **i05 예시 표기**: 구현 AI의 예로 PLAN-M2의 작업 묶음(A·B·D = implementer, C = implementer-fast)을 적었습니다. 사람·모델 이름은 넣지 않았습니다.
- 데모 폴더 `guidebook/demo-home`은 그대로 두었습니다(git 무시 대상). 8820 서버와 캡처용 Chrome은 껐고, 8765의 실제 서버는 건드리지 않았습니다.
