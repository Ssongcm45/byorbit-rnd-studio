예측값 옆의 근거 배지 4가지

예측 화면의 값마다 붙는 배지입니다. 배지를 보면 그 숫자를 얼마나 믿을지 알 수 있습니다.

문헌
DOI 확인
논문에서 가져온 값. DOI를 Crossref와 원문으로 확인했습니다.
믿을 때
조건이 그 논문이 다룬 범위 안일 때
의심할 때
범위 밖이면 ‘외삽’ 경고 — 오차가 커집니다
실측
n
내 CoA·내 실험에서 잰 값. n은 몇 개를 쟀는지입니다.
믿을 때
n이 클수록, 같은 원료·같은 방법일 때
의심할 때
n ≤ 2이면 ‘보정 신뢰도 낮음’
설비 사양
건조기 출력·용량 같은 설비 값. 설정 파일 equipment.json에 있음.
믿을 때
내 설비 값으로 고쳐 넣었을 때
의심할 때
기본값 그대로라면 내 설비와 다를 수 있음
가정
근거를 찾지 못해 일반적인 크기로 잡은 값입니다.
믿을 때
대략의 방향을 볼 때만
의심할 때
숫자 자체를 믿지 말고 내 측정으로 바꾸기

예측값은 측정값이 아닙니다. 중요한 결정 전에는 실제 시험으로 확인하세요.
