내 실험 데이터로 모델을 맞추는 순환

예측은 출발점일 뿐입니다. 내가 잰 값으로 비교하고 보정해서 다음 실험을 고릅니다.

공정 흐름 편집
원료 → 세척 → 압착 → 분쇄 → 건조 → 체분리 → 저장. 단계 추가·삭제·순서·값 고치기
내 데이터
런(한 번의 시험)마다 조건과 잰 값. 표 입력 또는 CSV·XLSX 가져오기
예측과 비교
잔차 = 실측 − 예측, 패리티 그림, MAE·RMSE
보정
미리보기로 전·후를 나란히 본 뒤 ‘적용’해야 반영
다음 실험 제안
비어 있는 온도 채우기·요인 배치 (‘제안’ 표시)
새 런을 실험해 데이터에 더하고 다시 비교

건조 단계는 ‘건조 방식’ 탭과 같은 예측 엔진을 씁니다. 세척·압착·분쇄·추출·저장의 계수는 대부분 가정이라, 내 값을 넣으면 ‘내 입력’으로 바뀝니다.
