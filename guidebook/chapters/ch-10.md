# 자료 넣고 찾기

이제 앱에 자료를 넣어 봅시다. 넣는 방법은 아주 쉽습니다. 파일을 끌어다 놓기만 하면 됩니다. 그 뒤에 앱이 무슨 일을 하는지 알아 두면, 검색이 왜 잘 되는지, 가끔 왜 안 되는지도 이해할 수 있습니다.

### 자료를 넣는 두 가지 방법

**방법 1. 끌어다 놓기**

1. 왼쪽 메뉴에서 **자료함**을 누릅니다.
2. 오른쪽의 보안 등급(일반·내부·기밀)을 먼저 고릅니다. 기본은 "내부"입니다.
3. 파일을 가운데 상자로 끌어다 놓거나 **파일 선택**을 누릅니다.

**방법 2. 받은편지함 폴더에 넣기**

데이터 폴더의 `inbox` 폴더에 파일을 복사합니다. 앱이 켜져 있으면 바로 알아채고 처리합니다. 여러 파일을 한꺼번에 넣을 때 편합니다.

자료 목록의 줄마다 **보기** (원문 청크와 라벨), **작업대** (11장), **AI 라벨** (11장) 단추가 있고, 끝의 **⋯** (더 보기)를 누르면 **원본 파일 열기**, **다시 처리**, **삭제…** 메뉴가 나옵니다.

![자료 카드의 ⋯ 메뉴 — 원본 파일 열기·다시 처리·삭제](s37-lib-menu.png "출처: R&D Studio V0.5 화면(예시 데이터) | width: 95%")

어느 방법이든 원본 파일은 그대로 두고, 사본이 데이터 폴더의 `library`로 들어갑니다. 같은 파일을 두 번 넣으면 앱이 중복으로 알아보고 다시 넣지 않습니다. 처리에 실패한 파일은 데이터 폴더의 `logs` 폴더에 이유가 기록됩니다.

![자료함 — 자료 목록(좁은 창에서는 자료마다 카드로 보임)](s01b-library-list.png "출처: R&D Studio V0.5 화면(예시 데이터)")

### 넣을 수 있는 파일

[표] 지원 형식과 처리 방법 | 자료: R&D Studio V0.5 README
| 형식 | 이렇게 읽습니다 |
|---|---|
| PDF | 본문과 표를 뽑습니다. 글자가 거의 없는 스캔 쪽은 OCR을 설치했으면 자동으로 읽고, 아니면 "OCR 필요"로 표시합니다 |
| 이미지(PNG·JPG·TIF) | 사진·스캔 CoA를 OCR로 읽습니다(설치 필요) |
| HWPX | 본문과 표를 뽑습니다. 옛 HWP는 한글에서 "HWPX로 저장"하거나 kordoc을 설치합니다 |
| XLSX | 표로 넣습니다. CoA 양식이면 시료와 측정값으로 바로 올리고, 등급을 "기밀"로 둡니다 |
| TXT · MD · CSV | 문단 단위로 넣습니다 |

**OCR**은 그림 속 글자를 컴퓨터가 읽을 수 있는 글자로 바꾸는 기술입니다(광학 문자 인식). 이 앱의 OCR은 내 PC에서만 돌아서 이미지가 밖으로 나가지 않습니다.

### 넣은 뒤에 일어나는 일

자료함 화면의 각 자료 줄에는 처리 단계가 표시됩니다. 앱은 자료 하나를 받으면 다섯 단계를 거칩니다.

![자료 처리 파이프라인](i07-pipeline.png "출처: 송창민 작성")

1. **파싱** — 파일을 열어 제목·본문·표를 꺼냅니다. 파싱(parsing)은 "구조를 읽어 낸다"는 뜻입니다.
2. **정규화** — 글자 모양을 고릅니다. 예를 들어 전각 숫자를 보통 숫자로, 여러 칸 띄어쓰기를 한 칸으로 바꿉니다.
3. **청킹** — 긴 문서를 검색하기 좋은 조각(청크)으로 자릅니다. 표는 "머리글: 값" 꼴로 풀어 둡니다.
4. **사전 라벨** — 개념 사전에 있는 낱말(부산물 이름, 성분 이름, 공정 이름 등)에 자동으로 표시를 붙입니다.
5. **적재** — 데이터베이스에 저장하고 검색 색인을 만듭니다.

여기까지는 AI 없이 내 PC 안에서 끝납니다. 그림의 오른쪽 점선 부분(AI 라벨 → 사람 검토 → 측정값)은 11장에서 다룹니다.

::: info 알아 두기
CoA 엑셀은 다섯 단계를 거치면서 측정값까지 바로 올라갑니다. 앱이 ByOrbit CoA 양식의 머리글(부산물종·건조방법·TDF·TPC·수분·중금속 등)을 알아보기 때문입니다. "ND·불검출"은 값 없이 글자로, "< 0.01"은 값 0.01과 원래 표기를 함께 남깁니다.
:::

## 검색하기 — 동의어까지

같은 것을 다르게 부르는 문제(2장)를 푸는 곳이 검색입니다.

1. 왼쪽 메뉴에서 **검색**을 누릅니다(위쪽 빠른 검색창에 바로 써도 됩니다).
2. 검색칸에 "사과 포마스 식이섬유"를 넣고 Enter를 누릅니다.
3. 검색칸 아래에 넓혀진 낱말이 칩(작은 단추 모양)으로 보입니다.
4. 결과를 누르면 오른쪽에 그 청크의 원문과 라벨이 보입니다. 그 자리에서 고치고 싶으면 **작업대에서 열기**를 누릅니다(11장). 결과 오른쪽 위의 "점수"는 넓힌 동의어가 본문에 몇 번 나왔는지로 매긴 간단한 점수입니다(5장).

![검색 — 넓혀진 동의어 칩](s02a-search-chips.png "출처: R&D Studio V0.5 화면(예시 데이터, 일부를 잘라 이어 붙임)")

![검색 — 결과를 누르면 열리는 청크 원문과 라벨 밑줄](s02b-search-chunk.png "출처: R&D Studio V0.5 화면(예시 데이터)")

앱은 "사과 포마스"를 사과박·apple pomace 같은 동의어로, "식이섬유"를 총식이섬유·TDF 같은 동의어로 넓혀서 찾습니다. 논문이 영어로 쓰였든 보고서가 줄임말을 썼든 함께 찾아집니다.

::: tip 따라 해 보기
예시 자료를 넣었다면 아래 세 검색어를 차례로 넣어 보고, 결과 수와 넓혀진 칩을 비교해 보세요.
1. 사과박
2. apple pomace
3. 사과 포마스 TDF
:::

검색이 낱말을 찾는 방법은 두 가지입니다. 세 글자 이상은 세 글자씩 잘라 둔 색인에서 빨리 찾고, 두 글자 이하(예: pH)는 본문을 한 줄씩 비교해 찾습니다(5장). 그래서 아주 짧은 말은 결과가 많이 나올 수 있습니다. 그럴 때는 낱말을 하나 더 붙여 좁힙니다.

### 개념 화면 — 동의어 사전 보기

검색이 동의어를 아는 것은 **개념 사전** 덕분입니다. 왼쪽 메뉴의 **개념 사전**에서 봅니다.

![개념 사전 — "건조"로 찾은 개념·동의어 표](s05a-concepts-synonyms.png "출처: R&D Studio V0.5 화면(예시 데이터)")

![개념 사전 — 부산물 분류 트리(앞부분)](s05b-concepts-tree.png "출처: R&D Studio V0.5 화면(예시 데이터)")

- 왼쪽은 **분류 트리**입니다. 농·임·수산 부산물이 나무 모양으로 정리되어 있습니다. 예: 과실 착즙박 → 사과박.
- 개념을 누르면 표준 이름과 동의어 목록이 나옵니다.
- 체계는 부산물·원물·공정·성분·물성·단위·시험법·용도로 나뉩니다.
- **지식그래프** 보기로 바꾸면 개념 사이 관계(상위 분류·원료·발생 공정·함유 성분)와 그 개념을 언급한 자료·측정값을 점과 선으로 봅니다. 자세한 설명은 6장에 있습니다.

처음 들어 있는 개념은 **표준 시드**입니다. 시드(seed)는 "씨앗"이라는 뜻으로, 처음 심어 둔 기본 자료를 말합니다. 우리 연구실에서만 쓰는 이름이 있다면 **내 확장** 개념으로 더할 수 있습니다. 표준 시드는 `seed.ttl`, 내가 더한 것은 `mine.ttl` 파일에 따로 저장되므로 섞이지 않습니다. 기존 개념에 줄임말을 동의어로 붙일 때는 11장 작업대의 "동의어로 배우기"를 씁니다. AI가 새 개념을 제안하는 경우도 있는데, 제안된 개념은 이 화면에서 사람이 승인해야 검색과 사전 라벨에 쓰입니다. 표준 시드에는 농·임·수산 부산물의 분류 골격과 사과박의 자세한 개념, 기본 동의어 사전이 들어 있습니다. 여기에 내 확장 개념과 배운 동의어가 쌓일수록 검색이 우리 연구실의 말에 가까워집니다.

::: tip 따라 해 보기
사전에 없는 부산물을 내 확장 개념으로 더해 봅시다.
1. **개념** 화면에서 새 개념 추가 칸을 엽니다.
2. 표준명에 "사과씨", 체계에 "부산물", 동의어에 "apple seed, 사과 씨앗"을 넣고 상위 개념으로 "과실 착즙박"을 고릅니다.
3. 저장한 뒤 **검색**에서 "apple seed"로 찾아봅니다. 이제 사과씨가 나온 청크가 함께 찾아집니다.
:::

::: info 핵심 정리
- 보안 등급을 먼저 고르고, 끌어다 놓거나 `inbox`에 넣습니다.
- 앱은 파싱 → 정규화 → 청킹 → 사전 라벨 → 적재를 내 PC 안에서 합니다.
- 검색은 개념 사전의 동의어로 넓혀 찾고, 사전은 내가 늘릴 수 있습니다.
- 같은 파일은 두 번 들어가지 않고, 실패한 파일은 logs 폴더에 이유가 남습니다.
- 자료 카드의 ⋯ 메뉴로 원본 파일을 열거나 다시 처리하고, 필요 없으면 삭제합니다.
- 위쪽 빠른 검색(Ctrl+K)으로 어느 화면에서든 바로 찾습니다.
:::
