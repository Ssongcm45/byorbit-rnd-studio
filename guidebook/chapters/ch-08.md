# 안전하게 쓰기

AI를 연구에 쓰기 전에 꼭 물어야 할 질문이 하나 있습니다. **"지금 무엇이 내 PC 밖으로 나가는가?"** 이 질문에 답할 수 없다면, 그 도구는 기밀 자료에 쓰면 안 됩니다. 이 장에서는 이 도구가 그 질문에 어떻게 답하는지 봅니다.

### 안과 밖의 경계

![PC 안에 남는 것과 밖으로 나가는 것](i04-security.png "출처: 송창민 작성")

그림의 가운데 선이 내 PC의 경계입니다. 왼쪽은 절대 나가지 않는 것, 오른쪽은 상황에 따라 나가는 것입니다. 앱의 **시작** 화면에 있는 **안전 상태** 카드가 지금 설정 기준으로 같은 내용을 보여 줍니다.

![시작 화면의 안전 상태 카드 — CoA 전송 규칙·AI 엔진·식품 영양 DB·원본 파일](s31b-home-safety.png "출처: R&D Studio V0.5 화면(예시 데이터)")

**나가지 않는 것**

- 원본 파일(PDF·HWPX·엑셀)
- 데이터베이스 전체
- CoA의 식별 정보(공급처·로트번호·시료번호)
- 실험 데이터와 통계 계산
- 청크 규칙·동의어 같은 "배운 것"

**나가는 것(언제, 어디로)**

- AI에 물을 때 → 질문과, AI가 도구로 꺼내 본 본문 일부(가린 상태) → AI 회사
- 자료 수집할 때 → 검색어와 그 출처의 API 키 → 그 학술 데이터베이스
- 분자 구조를 인터넷에서 가져올 때 → 영문 성분명 하나 → PubChem(미국 국립보건원이 운영하는 화학 물질 데이터베이스)
- 클라우드 파서를 쓸 때 → 문서 파일 전체 → Upstage(기밀 문서는 막힘)
- 식품 영양 DB를 켰을 때 → 식품명과 성분값 → 식품 DB(Neon). AI 지침은 `[가림]` 표시·로트번호·공급처·시료번호를 식품 도구에 넣지 말라고 정해 둡니다
- 로컬 OCR을 쓸 때 → 아무것도 보내지 않음(처음 한 번 인식 모델 파일만 내려받음)

두 번째 AI 엔진인 Codex로 돌릴 때도 같은 원칙입니다. 사용자의 Codex 설정(MCP·플러그인)은 싣지 않고, 셸·이미지 보기·브라우저·플러그인·웹 검색을 끈 채 읽기 전용으로 실행합니다. 2026년 11월 24일 실제 시험에서 Codex가 데이터 폴더의 파일을 직접 읽지 못하는 것을 확인했습니다.

### AI에게 넘어가는 것을 고르는 규칙

설정 화면에서 **CoA 규칙**을 고릅니다. 기밀 자료를 AI에게 어떻게 넘길지 정하는 규칙입니다.

[표] CoA 규칙 두 가지 | 자료: R&D Studio V0.5 README
| 규칙 | AI에게 넘어가는 것 |
|---|---|
| 필요한 값만·식별 정보 가림(기본) | 측정값과 본문은 넘기되 로트번호·공급처·시료번호는 `[가림]`으로 바꿉니다. 시료는 "시료 n"으로만 구분합니다 |
| 보내지 않기 | 기밀 자료의 본문과 측정값을 전혀 넘기지 않습니다 |

![설정 — CoA 전송 규칙](s07b-settings-coa.png "출처: R&D Studio V0.5 화면(예시 데이터)")

가림은 본문에서 끝나지 않습니다. 파일 이름에 공급처나 로트번호가 들어가는 일이 흔하므로, 기밀 자료의 파일명·제목·섹션 제목도 가립니다. 파일명은 `기밀자료-xxxxxx.확장자` 꼴로 바꿔 넘깁니다. 내 화면에서는 원래 이름이 그대로 보입니다.

## 다섯 겹의 안전장치

한 가지 장치만 믿으면 그 장치가 뚫릴 때 끝입니다. 그래서 여러 겹으로 막았습니다.

1. **AI의 손 묶기** — 5장에서 본 `--tools ""`로 AI의 파일 읽기·명령 실행·웹 검색 도구를 모두 뺍니다. AI는 이 앱의 도구 7개만 씁니다.
2. **도구 안에서 가리기** — 그 7개 도구가 본문을 돌려줄 때 기밀 식별 정보를 `[가림]`으로 바꿉니다.
3. **위험한 도구 막기** — 식품 영양 DB를 연결하면 도구가 더 생기는데, 그중 파일·URL을 읽는 `extract_label_table`은 켜짐 여부와 상관없이 늘 막습니다. 이것을 열면 1번 장치를 돌아갈 수 있기 때문입니다.
4. **화면 지키기** — 화면은 127.0.0.1 주소로만 열리고, 다른 웹사이트가 몰래 보낸 쓰기 요청은 막습니다.
5. **키는 환경 변수로만** — API 키를 설정 파일·데이터베이스·로그에 쓰지 않습니다. 오류 메시지에 키가 섞이면 `***`로 가립니다.

**환경 변수**는 Windows가 프로그램에게 건네주는 이름표 달린 값입니다. 파일에 적지 않으므로, 폴더를 복사하거나 공유해도 키가 따라가지 않습니다.

::: warn 주의
두 번째 AI 엔진인 Codex는 보안 시험을 다시 해야 하는 때가 있습니다. Codex 프로그램을 업데이트하면 파일 읽기가 여전히 막히는지 다시 시험해야 합니다. 더 엄격하게 쓰려면 환경 변수 `BYORBIT_CODEX_FORCE_BLOCK=1`을 지정합니다. 그러면 Codex로 돌릴 때는 기밀 수치를 늘 "보내지 않기"로 강제합니다.
:::

### 왜 AI에게 브라우저를 주지 않았나

AI가 웹 브라우저를 직접 조종하게 하는 도구(예: Playwright MCP)가 있습니다. 편리해 보이지만 이 프로젝트에서는 쓰지 않았습니다. 브라우저는 `file://` 주소로 내 PC의 파일도 열 수 있습니다. AI에게 브라우저를 주면, AI가 기밀 원본을 가림 없이 열어 볼 길이 생깁니다.

그래서 브라우저는 **크롤러 코드만** 정해진 규칙으로 씁니다. http와 https 주소만 열고, 허용한 사이트 경로만 갑니다. AI에게는 도구로 주지 않습니다. 편리함과 안전이 부딪힐 때 안전을 고른 예입니다.

### AI의 답을 언제 믿을까

안전에는 "새지 않게"만 있는 것이 아닙니다. **틀린 답을 믿지 않게** 하는 것도 안전입니다. 이 도구는 예측값과 답마다 근거 배지를 붙입니다.

![근거 배지 네 가지 읽는 법](i12-evidence.png "출처: 송창민 작성")

[표] 근거 배지와 믿는 정도 | 자료: docs/PREDICT-SOURCES.md
| 배지 | 뜻 | 이렇게 읽으세요 |
|---|---|---|
| 문헌(DOI 확인) | 실제로 읽은 논문의 값. 읽은 위치(표·절)가 함께 적힘 | 가장 믿을 만하지만, 논문 조건과 내 조건이 같은지 확인 |
| 실측 n= | 내 데이터베이스의 실제 측정값. n은 시료 수 | n이 1~2면 아직 약한 근거 |
| 설비 사양 | 설정에 적은 설비 값 | 처음 값은 일반 사양이니 내 설비 값으로 바꿔야 함 |
| 가정 | 문헌에서 수치를 확인하지 못한 값 | 출발점일 뿐. 내 실측으로 바꿔야 할 대상 |

여기에 **외삽 경고**가 붙을 때가 있습니다. 외삽은 근거 자료의 범위 밖을 짐작하는 것입니다. 예를 들어 문헌이 40~120 ℃만 실험했는데 150 ℃를 예측하면 "외삽 — 근거 범위 밖"이 뜹니다. 이 경고가 보이면 그 값은 참고만 합니다.

AI에게 물어서 받은 답도 마찬가지입니다. 답에 달린 출처를 따라가 원문을 직접 확인하는 습관을 들이세요. 출처가 없는 문장은 AI의 의견일 뿐입니다.

### 기밀 자료를 넣기 전에 확인할 것

이 장의 내용을 실제로 쓰는 순서로 묶으면 다섯 가지입니다.

1. 자료를 넣을 때 보안 등급을 **기밀**로 골랐는가? (엑셀 CoA는 자동으로 기밀이 됩니다)
2. 설정의 CoA 전송 규칙이 내가 원하는 쪽(가림 또는 보내지 않기)인가?
3. 그 자료를 클라우드 파서(Upstage)로 읽으려 하지 않는가? 기밀이면 앱이 막지만, 내부 자료도 보낼 때마다 다시 생각합니다.
4. 질문 문장에 공급처 이름이나 로트번호를 쓰지 않았는가? 질문은 가림 대상이 아닙니다.
5. 답의 숫자에 근거 배지와 출처가 붙어 있는가? 없으면 원문으로 확인합니다.
6. 식품 영양 DB를 켜 두었다면, 식품명과 성분값이 그 DB로 질의된다는 것을 알고 쓰는가?

하나라도 "아니오"라면 자료를 넣거나 질문하기 전에 먼저 고칩니다. 처음 몇 번은 이 목록을 옆에 두고 하나씩 짚어 보면, 곧 습관이 됩니다.

::: tip 따라 해 보기
내 설정이 어떻게 되어 있는지 확인해 봅시다.
1. 왼쪽 메뉴 맨 아래의 **설정**을 누릅니다.
2. **CoA 전송 규칙**이 "필요한 값만·식별 정보 가림"인지 봅니다.
3. 기밀 자료를 AI와 전혀 나누고 싶지 않다면 "보내지 않기"로 바꾸고 저장합니다.
:::

::: info 핵심 정리
- 원본 파일·데이터베이스·CoA 식별 정보는 PC 밖으로 나가지 않습니다.
- AI는 앱의 도구 7개만 쓰고, 그 도구가 기밀 식별 정보를 가립니다.
- 근거 배지(문헌·실측·설비·가정)와 외삽 경고를 보고 답을 믿을지 정합니다.
- 기밀 자료를 넣기 전에는 여섯 가지 확인 목록을 한 번씩 짚고, 설정의 CoA 전송 규칙을 확인합니다.
:::
