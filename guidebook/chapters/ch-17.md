# 부록

이 부록은 책상 옆에 펴 두고 쓰는 곳입니다. 첫째 절은 AI에게 일을 시킬 때 베껴 쓰는 요청 문장, 둘째 절은 쉬운 말 용어집, 셋째 절은 자주 막히는 곳의 해결법입니다.

## A. 따라 쓰는 요청 문장

### 기본 틀 — 네 가지 재료

4장에서 본 네 재료(목적·조건·결과물 모양·확인 방법)를 빈칸으로 만든 틀입니다. 괄호 안을 내 상황으로 바꿔 씁니다.

```text
[목적]   (무엇을 하고 싶은지 한 문장)
[조건]   (꼭 지킬 것: 기밀은 밖으로 보내지 않는다 / 근거를 표시한다 /
          모르면 모른다고 쓴다 / 이 파일들만 고친다)
[결과물] (화면·표·파일 중 무엇을, 어떤 모양으로)
[확인]   (다 됐는지 어떻게 알지: 시험 통과 / 화면 캡처 / 원문 대조)
```

### 만들 때 쓰는 문장(AI 코딩 도구에게)

이 프로젝트에서 실제로 쓴 요청을 단계별로 다듬었습니다.

[표] 단계별 요청 문장 | 자료: 이 프로젝트의 실제 요청을 다듬음
| 단계 | 요청 문장 |
|---|---|
| 1. 살펴보기 | "우선 이 폴더를 전체적으로 확인하고, 있는 것과 빠진 것을 보고해 줘. 아직 아무것도 고치지 마." |
| 2. 목적과 조건 | "온도를 바꾸면 예상 결과가 실시간으로 바뀌게 해 줘. 값마다 근거(논문·실측·설비·가정)를 표시하고, 근거가 없으면 숫자를 만들지 마." |
| 3. 결정 받기 | "내가 정해야 할 것이 있으면 선택지 2~4개로 물어봐 줘. 각 선택지의 장단점도 한 줄씩." |
| 4. 계약 문서 | "결정한 내용과 파일 담당, 부품끼리 만나는 약속을 docs/PLAN.md에 먼저 써 줘." |
| 5. 나눠 맡기기 | "계약대로 서로 다른 파일을 맡겨서 동시에 진행해 줘. 남의 파일은 고치지 않게." |
| 6. 검증 | "완료 보고를 믿지 말고 시험을 다시 돌리고, 화면을 캡처해서 보여 줘. 인용한 논문은 DOI로 확인해 줘." |
| 7. 마무리 | "확인 못 한 것과 한계를 문서에 그대로 적어 줘. 커밋은 내가 확인한 뒤에." |
| 버그 신고 | "검색칸에 글자가 입력되지 않아. 원인을 먼저 찾아서 설명하고, 고친 뒤 같은 일이 다시 안 생기게 시험도 하나 넣어 줘." |

### 쓸 때 쓰는 문장(앱의 AI에 묻기에서)

- "사과박 열풍건조 자료를 모두 찾아서 연도·조건·측정값을 표로 정리해 줘. 출처를 꼭 달고, 자료가 없는 칸은 '자료 없음'이라고 써 줘."
- "동결건조와 열풍건조 시료의 TPC를 비교해 줘. 같은 기준(건량)끼리만 비교하고, 기준이 다르면 따로 표시해 줘."
- (리포트 작성자) "사과박 식이섬유 소재화 현황 보고서 초안을 써 줘. 문장마다 근거 번호를 달고, 근거 없는 주장은 넣지 마."

## C. 문제 해결

### 설치와 실행

**PowerShell이 스크립트 실행을 막아요.**
install.ps1을 직접 열지 말고 `install.bat`을 더블클릭하세요. 이번 실행에만 실행 정책을 우회합니다.

**"Python 3.11 이상이 필요합니다"가 나와요.**
파이썬 설치 때 "Add to PATH"를 빠뜨렸을 가능성이 큽니다. 다시 설치하며 체크하고, PC를 껐다 켠 뒤 install.bat을 다시 실행합니다.

**"먼저 install.bat 을 실행하세요"가 나와요.**
start.bat을 install.bat보다 먼저 눌렀습니다. install.bat을 끝까지 실행한 뒤 다시 시도합니다.

**연결 점검이 실패해요.**
PowerShell에서 `claude`를 실행해 로그인이 되어 있는지 봅니다. 프로그램 폴더의 `check-claude.bat`으로도 점검할 수 있습니다.

### 자료와 검색

**PDF를 넣었는데 "OCR 필요"가 떠요.**
글자층이 없는 스캔 PDF입니다. `install-ocr.bat`을 실행한 뒤 작업대 파싱 탭에서 RapidOCR로 다시 읽습니다.

**옛 한글 파일(.hwp)이 안 들어가요.**
한글에서 "HWPX로 저장"한 뒤 넣거나, `install-kordoc.bat`을 실행합니다.

**두 글자 낱말로 찾으니 결과가 너무 많아요.**
짧은 말은 단순 비교로 찾으므로 많이 걸립니다. 낱말을 하나 더 붙여 좁힙니다(예: "pH" → "pH 사과박").

**Docling으로 처음 읽을 때 한참 걸려요.**
정상입니다. 처음 변환할 때 레이아웃·표 모델(약 500MB)을 한 번 내려받기 때문에 30초 넘게 걸립니다. 그다음부터는 훨씬 빨라집니다.

**kordoc으로 PDF를 읽으니 "글자 없음"이 나와요.**
알려진 한계입니다. kordoc은 한글 CID 글꼴로 만든 PDF를 못 읽는 경우가 있습니다. PDF는 PyMuPDF·pdfplumber·Docling으로 읽고, kordoc은 HWP·HWPX에 씁니다.

**Upstage 버튼이 잠겨 있어요.**
기밀 문서는 클라우드 파서로 보낼 수 없습니다. 로컬 도구(pdfplumber·Docling·RapidOCR)를 씁니다.

**검색 결과가 하나도 안 나와요.**
오른쪽 위에서 다른 프로젝트가 골라져 있지 않은지 봅니다. 검색은 지금 프로젝트의 자료만 찾습니다.

### 수집과 분석

**국내 출처가 흐리게 보여요.**
API 키가 없습니다. 출처 밑의 **설정에서 키 넣기**를 눌러 키를 저장하고 **연결 시험**을 합니다. 앱을 다시 켤 필요는 없습니다(13장).

**Semantic Scholar가 자꾸 막혀요.**
키 없이 쓰면 자주 잠시 막힙니다. 선택 키를 받아 API 키 관리에 넣거나, 잠시 뒤 다시 하거나 다른 해외 출처를 씁니다. 한 출처가 실패해도 다른 출처의 결과는 그대로 수집함에 들어옵니다.

**키를 저장했는데 '환경 변수'로 표시되고 바뀌지 않아요.**
같은 이름의 환경 변수가 있으면 그 값이 먼저 쓰입니다. 앱은 환경 변수를 바꾸거나 지우지 않으니, Windows의 환경 변수 설정에서 그 이름을 지우고 앱을 다시 켭니다.

**국내 출처의 첫 검색 결과가 이상해요.**
국내·키 필요 출처 7개 중 6개는 실제 키로 확인하지 못했습니다. 결과를 눈으로 확인하고, 이상하면 그 출처 모듈 머리 주석의 "확인 필요" 항목을 개발 담당자와 함께 봅니다.

**크롤러로 아무 누리집이나 모아도 되나요?**
아닙니다. robots.txt와 이용약관을 먼저 보고, 공식 API가 있으면 API를 씁니다. 이 앱은 robots.txt가 막은 주소에 가지 않고, 약관을 확인하지 못한 사이트는 꺼 둡니다(13장).

**Playwright MCP를 앱에 붙이면 더 편하지 않나요?**
편하지만 이 앱은 일부러 붙이지 않습니다. AI가 브라우저로 PC 파일을 열어 기밀 가림을 돌아갈 수 있기 때문입니다. 필요하면 기밀이 없는 다른 폴더의 내 Claude Code에서 따로 씁니다.

**R에서 낸 t값의 부호가 앱과 반대예요.**
정상입니다. 앱은 "비교 − 기준", R의 `t.test`는 "기준 − 비교"로 계산합니다. p값은 같습니다.

**AI 라벨이 "중단됨"으로 보여요.**
앱을 끈 사이에 끝나지 못한 실행입니다. 자료함의 AI 라벨 카드에서 **재시도**를 누르면 남은 청크만 이어서 처리합니다.

### 개발 도구

**GitHub에 올리면 남이 볼 수 있나요?**
공개 저장소면 누구나 보지만, 이 프로젝트처럼 비공개 저장소(`--private`)로 만들면 내가 초대한 사람만 봅니다. 그래도 키와 비밀번호는 올리지 않습니다(7장).

**이 앱을 인터넷 주소로 열어 팀원과 같이 쓸 수 있나요?**
권하지 않습니다. 로그인이 없고 내 PC 주소로 온 요청만 받도록 만들었습니다. 함께 쓰려면 로그인과 권한이 있는 팀용 버전을 따로 만들어야 합니다.

**지식그래프가 너무 복잡해 보여요.**
위쪽의 선 칩에서 필요 없는 관계(예: 언급)를 끄고, 깊이를 1단계로 둡니다. **맞춤**을 누르면 전체가 화면에 맞춰지고, 그림 아래 이웃 목록에서 글자로 볼 수도 있습니다.

### 백업과 옮기기

**자료를 다른 PC로 옮기고 싶어요.**
앱을 끄고 데이터 폴더(`C:\Users\<이름>\ByOrbit-RD`)를 통째로 복사합니다. 새 PC에서 install.bat을 실행한 뒤 그 폴더를 같은 자리에 놓습니다. 다른 위치를 쓰려면 환경 변수 `BYORBIT_HOME`을 지정합니다. API 키는 이 PC의 자격 증명 관리자에 있어 따라가지 않으니, 새 PC의 API 키 관리에서 다시 넣습니다. 옮긴 뒤에는 자료함과 측정값 화면을 열어 자료가 다 보이는지 확인합니다.
