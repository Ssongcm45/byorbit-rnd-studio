# 설치하고 켜기

여기서부터는 직접 해 보는 부분입니다. Windows PC 한 대와 인터넷만 있으면 됩니다. 설치는 크게 다섯 걸음입니다. 앞의 두 걸음은 처음 한 번만 하고, 뒤의 걸음은 프로그램 폴더에서 더블클릭만 하면 됩니다.

### 준비물

- Windows PC(이 책은 Windows 11 기준)
- 인터넷 연결(설치할 때와 AI를 쓸 때 필요)
- Claude 계정(Claude Code에 로그인할 때 필요)
- R&D Studio V0.5 프로그램 폴더(비공개 GitHub 저장소에서 받거나 담당자에게 받습니다)

## 다섯 걸음 설치

### 1걸음. 파이썬 설치

**파이썬**은 이 프로그램이 쓰여진 언어입니다. 3.11 이상이 필요합니다.

1. 시작 메뉴에서 **PowerShell**을 찾아 엽니다. 파란 창이 뜹니다.
2. 아래 명령을 입력하고 Enter를 누릅니다.

```powershell
winget install Python.Python.3.12
```

python.org에서 설치 파일을 받아 설치해도 됩니다. 이때 첫 화면의 **"Add to PATH"를** 꼭 체크합니다. 체크하지 않으면 다른 프로그램이 파이썬을 찾지 못합니다.

### 2걸음. Claude Code 설치와 로그인

1. 같은 PowerShell 창에 아래 명령을 넣습니다.

```powershell
irm https://claude.ai/install.ps1 | iex
```

2. 설치가 끝나면 `claude`라고 입력하고 Enter를 누릅니다.
3. 안내에 따라 브라우저에서 로그인합니다. 로그인은 한 번만 하면 됩니다.

### 3걸음. install.bat 더블클릭

프로그램 폴더를 열고 **`install.bat`을** 더블클릭합니다. 검은 창이 뜨고 다섯 단계가 차례로 지나갑니다.

![install.bat을 실행했을 때 창에 나오는 글](s23a-install.png "출처: install.bat 실제 출력을 터미널 모양으로 재구성 | width: 85%")

창에 나오는 다섯 줄의 뜻은 이렇습니다.

[표] 설치 다섯 단계가 하는 일 | 자료: install.ps1
| 창의 글 | 하는 일 |
|---|---|
| [1/5] Python 확인 | 3.11 이상 파이썬을 찾습니다 |
| [2/5] 가상환경: .venv | 이 프로그램만 쓰는 작은 파이썬 방을 만듭니다. 다른 프로그램과 부품이 섞이지 않게 합니다 |
| [3/5] 패키지 설치 완료 | 필요한 부품(5장의 표)을 내려받습니다 |
| [4/5] 데이터 폴더 준비 완료 | 데이터 폴더·데이터베이스·표준 개념·AI 연결 설정을 만듭니다 |
| [5/5] Claude Code 확인 | Claude Code가 설치되어 있는지 봅니다 |

마지막에 초록색으로 "설치가 끝났습니다"가 나오면 성공입니다. 아무 키나 눌러 창을 닫습니다.

::: warn 주의
`[!] Python 3.11 이상이 필요합니다`가 나오면 1걸음이 덜 된 것입니다. PATH 체크를 빠뜨렸을 가능성이 큽니다. 파이썬을 다시 설치하면서 체크한 뒤, PC를 한 번 껐다 켜고 install.bat을 다시 실행하세요. `[5/5] Claude Code를 찾지 못했습니다`가 나오면 2걸음으로 돌아갑니다.
:::

### 4걸음. start.bat 더블클릭

이제 매일 쓰는 버튼입니다. **`start.bat`을** 더블클릭하면 검은 창이 하나 뜨고, 잠시 뒤 브라우저가 저절로 열립니다. 주소는 `http://127.0.0.1:8765`입니다.

검은 창은 프로그램의 엔진실입니다. **앱을 쓰는 동안 닫지 마세요.** 다 쓰고 끌 때는 검은 창을 누르고 Ctrl+C를 누릅니다.

### 5걸음. 연결 점검

AI가 정말 연결됐는지 확인합니다.

1. 왼쪽 메뉴 맨 아래의 **설정**을 누릅니다.
2. 엔진 카드에서 **연결 점검(실제 호출)을** 누릅니다.
3. "통과"가 나오면 끝입니다.

![설정 — AI 엔진 카드와 연결 점검 단추](s07a-settings-engine.png "출처: R&D Studio V0.5 화면(예시 데이터)")

설정 화면에는 연결 점검 말고도 중요한 칸이 모여 있습니다.

- **AI 엔진** — Claude Code(기본) 또는 Codex
- **CoA 전송 규칙** — 8장에서 본 "가림" 또는 "보내지 않기"
- **기본 프로젝트**와 **데이터 폴더 경로**
- **API 키 관리** — 국내 자료 출처·Apify·Upstage 키를 Windows 자격 증명 관리자에 저장합니다(13장)
- **식품 영양 DB 연결** — 켜면 AI가 농촌진흥청 원물·식약처 식품 성분 DB와 견줘 볼 수 있습니다(선택 기능, 읽기 전용 도구 12개)

## 예시 자료로 연습하기

처음부터 진짜 자료를 넣지 말고, 가짜 예시 자료로 연습합니다. 가장 쉬운 길은 **시작** 화면의 처음 사용 체크리스트에서 "자료 넣기" 줄의 **예시 자료 넣기** 단추를 누르는 것입니다(3장). 명령창이 편하면 프로그램 폴더에서 PowerShell을 열고(폴더 빈 곳에서 오른쪽 단추 → "터미널에서 열기") 아래 명령을 넣어도 같습니다.

```powershell
.venv\Scripts\python -m app.cli samples --project "사과박 식이섬유"
```

가상 논문 PDF, CoA 엑셀, HWPX 보고서, 메모, 그리고 건조 방법을 비교할 열풍건조 CoA가 받은편지함에 들어갑니다. 수치는 모두 가짜입니다. 단추로 넣으면 지금 고른 프로젝트로, 명령으로 넣으면 `--project`로 정한 프로젝트로 들어갑니다. 자료함 화면을 보면 하나씩 처리되는 모습이 보입니다.

### 더 깔 수 있는 것(선택)

기본 설치만으로도 앱은 다 돌아갑니다. 필요할 때만 아래를 더 설치합니다. 모두 프로그램 폴더에서 더블클릭합니다.

- **install-ocr.bat** — 스캔 PDF·사진의 글자 인식. 처음 한 번 인식 모델 3개(약 23MB)를 받고, 이미지는 PC 밖으로 나가지 않습니다.
- **install-docling.bat** — 2단 논문·복잡한 표를 잘 읽는 고급 파서. 약 1.5GB이고 첫 실행에 30초 이상 걸립니다.
- **install-kordoc.bat** — 한글 파일(.hwp·.hwpx)과 한글 PDF 읽기. Node.js 18 이상(PDF는 20.6 이상 권장)이 필요하고 약 100MB입니다.
- **install-browser.bat** — 자바스크립트로 그리는 웹 목록 크롤링(13장). 이 PC에 설치된 Chrome을 씁니다.

설치 여부는 작업대 파싱 탭과 크롤러 사이트 카드의 "준비됨"·"미설치" 표시로 확인합니다.

::: info 핵심 정리
- 처음 한 번: 파이썬 설치(PATH 체크) → Claude Code 설치와 로그인 → install.bat.
- 매일: start.bat 더블클릭, 끌 때는 검은 창에서 Ctrl+C.
- 설정 → 연결 점검에서 "통과"를 보고, 예시 자료로 먼저 연습합니다.
:::
