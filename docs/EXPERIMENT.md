# 내 실험 — 공정 흐름 위에서 내 데이터로 실험하기

내가 가진 공정 조건·측정값을 넣고, 공정 흐름(원료 → 전처리 → 건조 → 분말화 → 추출 → 저장)을 따라 예측한 값과 비교하고, 내 데이터로 건조 예측을 보정한다.
모든 계산은 이 컴퓨터 안에서만 한다. 실험 자료를 밖으로 보내는 길은 없다('기밀' 실험도 같다).

- 코드: `app/experiment/`(steps·store·sim·importer·calib·plan), API `app/routes_experiment.py`(`/api/exp`), 화면 `app/static/exp/exp.js`
- 단독 확인 페이지: `/static/exp/dev.html?exp=first&tab=flow|data|result&step=dry1&open=1&cal=1&theme=dark`
- 근거 목록: 새 단계의 계수는 `app/experiment/steps_sources.json`, 건조는 `app/viz/predict_sources.json`(설명: `docs/PREDICT-SOURCES.md`)

## 1. 쓰는 법

1. **새 실험**: 이름·흐름 틀·부산물·보안 등급(일반·내부·기밀)을 고른다. 틀은 복사되어 이 실험만의 흐름이 된다.
   - 틀: 사과박 동결건조 분말 / 사과박 열풍건조 분말 / 사과박 열풍건조 + 에탄올 추출
2. **공정 흐름 탭**: 단계를 끌어 순서를 바꾸거나 ←·→ 단추를 쓴다. '+ 단계'로 넣고, '끄기'로 건너뛰고(데이터는 그대로), ✕로 지운다.
   단계를 누르면 아래에서 값을 고친다. 단계 사이 막대는 흐름의 질량(갈색 건물 + 파란 물)과 TPC 잔존율이다(흐름 기본값으로 모의).
   건조 단계의 '건조 방식 탭에서 보기'는 같은 방식의 건조 예측 화면을 연다.
3. **실험 데이터 탭**: 런(한 번의 시험)마다 조건(파란 열, 비우면 흐름 기본값)과 내가 잰 값(갈색 열)을 넣는다.
   값 칸에는 숫자, `ND`(불검출), `< 0.01`·`0.01 미만`(검출 한계)를 넣을 수 있다. 'CSV·XLSX 가져오기'와 'CSV 내보내기'가 있다.
4. **결과·보정 탭**: 예측 대 실측 표(잔차 = 실측 − 예측), 패리티 그림, 런별 잔차, 대상별 오차 요약(MAE·RMSE·편향·MAPE·폭 안 n),
   민감도(값 하나를 훑은 곡선 + 내 실측 점), 보정 미리보기·적용, 다음 실험 제안을 본다. 예측값마다 '근거'를 펼치면 식·파라미터·출처가 나온다.

## 2. 흐름 모델

흐름(stream) = 습량 kg, 건물 kg, 물 kg, 수분 % 습량, TPC·TDF(원료 대비 남은 비율), 입자 크기.
TPC·TDF 농도(건량) = 원료 농도 × 남은 비율 × 원료 건물 ÷ 지금 건물. 원료 TPC를 모르면 TPC는 잔존율(원료 대비 %)로만 계산한다.

**질량 수지 원칙**: 건물은 보존한다. 줄어드는 것은 단계가 밝힌 손실·분리만큼이다(단계마다 `들어온 건물 = 나간 건물 + 밝힌 손실`을 확인해 보인다).

| 단계 | 모델 | 근거 |
|---|---|---|
| 원료 투입 | 투입량·수분·TPC·TDF. 비우면 수분은 CoA·적용한 실험의 생시료 수분 평균 → 가정 78%, TPC는 동결건조 실측 평균, TDF는 실측 평균 | 실측(있으면) / 가정 |
| 세척 | 물_후 = 물_전 + 습량 × 남는 표면 물(3%), 수용성 고형분 손실 1% 건물, TPC 손실 2% | **가정**(값을 넣으면 '내 입력') |
| 탈수·압착 | 압착액 L: (물 − (1−c)L) ÷ (건물 − cL + 물 − (1−c)L) = 압착 후 수분, 용해 고형분 c = 8%. TPC 손실률 = (잃은 건물 ÷ 건물) × 1 | **가정** |
| 분쇄 | 입자 크기만 바꾸고 기계 잔류 0.5%. 건조 단계에서 '두께 기준 = 분쇄 입자 크기'를 고르면 입자 크기를 건조 두께로 씀 | **가정** |
| 건조 | `app/viz/predict.py`의 `predict()`를 그대로 부른다 — 건조 방식 탭과 같은 값(공정 끝 수분·폭, TPC 잔존율, 목표 수분 도달 시간, 비에너지)과 같은 근거. 건조 입력 수분 = 흐름에 들어온 수분. 건물은 그대로, 물만 공정 끝 수분까지. TDF는 보존 | 문헌(Llavata 2022 등, DOI 확인) + 가정 + 설비 사양 + 실측 보정 |
| 분쇄·체분리 | 통과 수율: 넣으면 그 값, 아니면 체 눈 크기별 가정 표(75 µm 50% … 1000 µm 98%, 선형 보간), 회수 손실 1%. 성분 농도는 같다고 봄 | **가정** |
| 추출 | Y = Ymax·exp(−½((c − c_opt)/σ)²)·(1 − e^(−k(T)·t)), Ymax 80%, c_opt 60% v/v, σ 35, k(50 ℃) 0.10 /min, Ea 20 kJ/mol, 고형분 25%. 잔사가 흐름으로 이어지고 추출물은 따로 보임 | **가정**(전부) |
| 포장·저장 | X(t) = Xe(RH) + (X0 − Xe)·e^(−k_포장·t), Xe는 GAB(문헌). TPC는 e^(−k25·Q10^((T−25)/10)·t), k25 0.001 /일, Q10 2 | GAB만 문헌, 나머지 **가정** |

**문헌 근거 현황**: 새 단계(세척·압착·분쇄·체분리·추출·저장)의 계수는 원문에서 수치를 직접 읽어 확인한 문헌이 없어서 모두 '가정'으로 표시했다.
저장 단계의 평형 수분(GAB 상수, Llavata 2022 §2.3)만 건조 예측의 문헌 값을 빌려 쓴다. 건조 단계는 건조 예측의 근거를 그대로 따른다.
가정 값은 단계 값 칸에 내 값(예: 압착액 Brix → 용해 고형분)을 넣으면 '내 입력'으로 바뀐다.

**대상 이름**(예측과 실측이 만나는 이름): 수분(% 습량), 질량(kg), 건물 수율(%), TPC(mg GAE/g 건량), TPC 잔존율(원료 대비 %), TDF(g/100 g 건량),
목표 수분 도달 시간(h), 비에너지(kWh/kg 물), 건조 에너지 합계(kWh), 체 통과 수율(%), TPC 추출 수율(% TPC), 추출 TPC(mg GAE/g 투입 분말), 추출 고형분 수율(%).
'TPC 잔존율'은 원료 대비 누적값이다(건조만의 잔존율은 근거의 건조 예측 값).

## 3. 가져오기 형식

첫 줄에 열 이름, 둘째 줄부터 한 줄에 한 런. CSV(UTF-8·CP949, 쉼표·세미콜론·탭)나 XLSX(첫 데이터 시트).
올린 파일은 앱 메모리에만 1시간 두고, 자료함·받은편지함에 넣지 않는다.

열 이름으로 역할을 짐작하고, 미리보기에서 열마다 역할(런 이름·날짜·비고·조건·실측값·무시)·단계·항목·단위·기준을 고칠 수 있다.

- 런 이름: `런`, `run`, `시료명`, `이름`, `번호` / 날짜: `날짜`, `date` / 비고: `비고`, `메모`
- 조건: `원료 수분`, `원료 TPC`, `압착 후 수분`, `건조 방식`, `건조 온도`, `건조 시간`, `풍속`, `두께`, `압력`, `입자`, `체 눈`, `에탄올`, `추출 온도`, `추출 시간`, `용매비`, `포장`, `저장 기간`, `저장 온도`
- 실측값: `수분`, `TPC`/`폴리페놀`, `TDF`/`식이섬유`, `잔존율`, `체 통과 수율`, `추출 수율`, `비에너지` …
  앞말로 단계를 고른다: `건조 후 ~`(건조), `분말 ~`(체분리), `저장 후 ~`(저장), `압착 후 ~`(압착). 없으면 건조 단계.
- 단계를 직접 지정: `[dry1] 수분 (%)`처럼 대괄호에 단계 키(또는 단계 이름). 내보내기 CSV가 이 형식이라 그대로 다시 가져올 수 있다.
- 단위: 열 이름 괄호 속 단위를 표준 단위로 바꾼다 — mg GAE/100 g → mg GAE/g(÷100), µg/g → mg/g, g/kg → g/100 g(TDF), min → h, kPa·mbar·Torr → Pa, ℉ → ℃, kg/kg(건량 수분) → % 습량.
- 기준: 열 이름에 `건량`/`습량`(db·wb)이 있으면 그 기준. TPC·TDF는 적혀 있지 않으면 건량으로 본다. 습량 값은 비교할 때 같은 단계 수분(실측, 없으면 모의)으로 건량으로 바꾼다.
- 값: 숫자, `ND`·`불검출`(값 없음), `< 0.01`·`0.01 미만`(검출 한계 — 값 0.01을 남기되 잔차·보정에서 뺀다). 숫자가 아닌 글자는 그 행을 오류로 건너뛴다(행 번호와 이유를 보인다).

예시 CSV(열풍건조 틀):

```csv
런,날짜,원료 수분(%),원료 TPC (mg GAE/g 건량),압착 후 수분(%),건조 온도(℃),건조 시간(min),건조 후 수분(%),TPC (mg GAE/100 g 건량),총식이섬유(g/100 g),체 통과 수율(%),비고
A-50,2026-11-01,78.2,9.1,64.8,50,600,21.5,610,48.1,82.5,
A-60,2026-11-02,78.0,9.0,65.1,60,600,12.4,540,47.6,84.0,
A-70,2026-11-03,77.8,9.2,64.9,70,600,7.9,505,47.9,83.1,
A-80,2026-11-04,78.1,9.0,65.0,80,480,6.8,< 450,ND,85.2,검출 한계 표기
```

## 4. 보정 규칙 (내 데이터로)

1. **적용해야 쓴다**: '보정 미리보기'는 저장하지 않는다. '보정에 적용'을 누른 실험만 `<데이터 폴더>/config/calibration.json`(부산물별)에 들어가고,
   그때부터 건조 방식 탭의 예측에도 같은 보정이 쓰인다. '보정에서 빼기'로 되돌린다. 지운 실험은 자동으로 빠진다.
2. **무엇을 쓰나**: 흐름의 첫 번째 켜진 건조 단계에서 잰 값. 시료 이름은 `실험 <이름> · 런 n` — 런 라벨·로트·공급처·시료번호는 쓰지 않는다.
   - 건조 전 수분: 건조 바로 앞쪽 단계에서 잰 수분 → (그 사이에 세척·압착처럼 수분을 바꾸는 단계가 있으면 못 씀) → 런·흐름에 넣은 원료 수분·압착 후 수분을 앞 단계 모델로 이은 값. 둘 다 없으면 그 런은 건조 속도 보정에 쓰지 않는다.
   - TPC: 건조 전 TPC(앞 단계 실측 또는 원료 TPC 조건)가 있으면 그 런의 건조 전후 비율을 잔존율로 쓴다(원료 차이가 섞이지 않음). 없으면 CoA와 같이 동결건조 평균을 기준(잔존율 1)으로 쓴다.
   - 동결건조 런의 TPC는 기준값(평균)에 들어간다. 속도 보정은 열풍건조 런만 한다.
3. **n은 CoA와 내 실험을 함께 센다**: 예) `실측 n=5 (CoA 1 · 내 실험 4)로 보정`.
4. **배율만 맞춘다(기본)**: r = k_실측 ÷ k_문헌(T)의 기하평균. 내 실험 런은 기록한 두께·풍속의 배율(두께 지수·풍속 지수 — 가정)을 곱한 k_문헌과 비교한다. 배율 맞춤 RMSE(ln k)를 보인다.
5. **Ea는 서로 다른 온도가 3개 이상일 때만, 그리고 고를 때만**: ln r = α + β(1/T − 1/T_ref)로 맞추고 Ea_보정 = Ea_문헌맞춤 − β·R. 5–150 kJ/mol 밖이면 쓰지 않는다.
   온도가 3개 미만이면 맞추지 않고 문헌 맞춤 Ea(약 28.7 kJ/mol, TPC 약 22.2 kJ/mol)를 그대로 쓴다.
6. **폭을 넓힌다**: n ≤ 2이면 '보정 신뢰도 낮음'과 함께 불확실 폭 ×1.5, 그 밖에는 max(×1.2, e^RMSE(ln k)), 최대 ×3.
7. **문헌을 몰래 바꾸지 않는다**: 미리보기는 보정 전(지금 설정에서 이 실험을 뺀 것)·뒤를 나란히 보이고, 점마다 '문헌만 예측 → 보정 후 예측'과 잔차 전→후를 보인다.
   보정에 쓴 런과 같은 런을 비교하면 '표본 내 비교'라고 표시한다(실제 예측 오차보다 작게 보인다).

## 5. 다음 실험 제안

'제안'이라는 표시가 붙는다 — 모델의 불확실 폭과 지금까지의 런 조건만 보고 고른 조건이라, 설비·원료·안전은 직접 판단한다.

- **빈 온도 채우기**: 근거 범위(열풍·진공·자연: Llavata 2022 표 1의 40–120 ℃, 동결: 2차 건조 가정 0–50 ℃) 안에서 지금 런 온도와 가장 먼 온도(서로 10 ℃ 이상 떨어진 3개). 예측 폭이 넓을수록 앞에 둔다. Ea를 맞추려면 온도가 몇 개 더 필요한지 알려 준다.
- **요인 배치**: 건조 온도 3수준(기본 ±15 ℃) × 시간 2수준(목표 수분 도달 예상 시간의 0.75·1.25배), 추출이 있으면 에탄올 40·60·80% × 온도 40·60 ℃. 이미 한 조건은 지워 보인다.
- '이 배치로 빈 런 만들기'는 계획을 `experiment_plan`에 남기고 조건만 채운 런을 만든다(실측은 실험하면서 채운다).

## 6. 한계

- 세척·압착·분쇄·체분리·추출·저장 계수는 모두 가정이다. 이 단계들의 예측은 '내 실측을 넣고 비교'하는 출발점으로만 쓴다.
- 흐름은 직선이다(갈래 없음). 압착액·체 위 잔류분·추출물은 '분리'로 보이기만 하고 따로 흐르지 않는다.
- 건조 보정은 흐름의 첫 건조 단계, 열풍건조 런만 쓴다. 두께·풍속 배율 지수는 가정이므로 두께·풍속이 문헌 조건(3 mm, 0.9 m/s)과 많이 다르면 보정 배율에 그 오차가 섞인다.
- CoA 시료 값을 원료 기본값으로 쓰면(원료 TPC·TDF를 비워 둔 경우), 그 시료가 이미 앞 공정을 거친 것일 수 있어 세척·압착 뒤 농도가 높게 나올 수 있다 — 원료 값을 재서 넣는다.
